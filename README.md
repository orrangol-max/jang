# 제주, 나에게 맞게

2026 제주 관광 데이터 활용사례 공모전 개인 프로젝트. 관심사 기반 제주 여행지도, 수정 가능한 여행 예산, 원본 CSV 기반 통계 패널을 구현합니다.

**Codex 앱에서 시작하려면 [HANDOFF.md](HANDOFF.md)를 먼저 읽으세요.**

## 로컬 실행

Node.js 20 이상과 Python 3가 필요합니다. 외부 런타임 패키지는 없어 `npm install`은 필요하지 않습니다.

1. `data/raw/` 폴더를 만들고 아래 원본 CSV 5개를 넣습니다. 원래 한국어 파일명 그대로 사용할 수 있습니다.
   - 제주 연령대별 방문.csv
   - 제주여행 1인당 여행경비.csv
   - 제주여행 체류기간.csv
   - 제주 지역별 방문객(읍면동).csv
   - 제주여행 내국인관광객 세부 만족도.csv
2. 프로젝트 폴더에서 다음을 실행합니다. Windows에서는 `python` 대신 `py`를 사용할 수 있습니다.

```sh
python scripts/prepare-data.py
npm test
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. `npm run build`로 생성한 `public/index.html`은 단일 파일로도 열 수 있습니다.

원본 CSV·파생 통계·생성 HTML·공모전 첨부자료는 공개 저장소에 포함하지 않습니다. 인기 장소 대용량 CSV는 아직 분석하지 않았으며 로컬에서 추가 분석할 예정입니다.

## 데이터 해석

연령별 방문과 지역별 방문을 결합한 연령별 선호 장소 통계는 없습니다. 현재 장소 태그·개념도·예산 비용은 예시이며, 실제 통계와 화면에서 구분합니다. 자세한 범위는 [데이터 설명](data/README.md), 구조는 [개발 문서](DEVELOPMENT.md)를 참고하세요.
