# 데이터 출처와 범위

사용자가 제주관광빅데이터플랫폼에서 확보해 이 대화에 제공한 CSV 5개를 개발 환경의 `raw/`에 보관했습니다. GitHub에는 포함하지 않으므로 로컬 실행 시 사용자가 이 폴더를 만들고 CSV를 넣어야 합니다. 한국어 원래 파일명 그대로 사용 가능합니다. 파일 수신일: 2026-10-19. 다운로드 일자 및 재배포 허용 여부는 별도 확인되지 않았으므로 공개 배포 전 이용 조건을 확인해야 합니다. 원본과 파생 통계는 공개 저장소에서 제외합니다.

- `age-visits.csv`: 제주 연령대별 방문. 1,288행, 2019.01~2026.08(92개월), 시도코드 50, 성별 M/W, 연령코드 10/20/30/40/50/60/70. 방문객수 단위는 플랫폼 화면의 ‘명’을 참고. 실인원 중복 제거·관광객 정의는 원본 CSV에 없음.
- `travel-expenses.csv`: 제주여행 1인당 여행경비. 36행, 2014~2025, 내국인/외국인/크루즈. 내국인 원 단위는 사용자가 제공한 플랫폼 화면에서 확인. 외국인·크루즈 통화 단위는 확인되지 않아 웹 통계에서 제외. 지출 포함 항목·표본·가중치는 CSV에 없음.
- `stay-duration.csv`: 제주여행 체류기간. 36행, 2014~2025, 내국인/외국인/크루즈. 내국인 ‘일’, 크루즈 ‘시간’ 구분은 플랫폼 화면 참고. 웹에서는 내국인만 사용.

가공은 성별 합산과 연령별 구성비 및 전년 동월 변화만 수행합니다. 60대 이상 UI는 원본 코드 60·70의 합계이며 코드 70의 정확한 상한은 확인되지 않았습니다. 방문 통계와 여행실태조사 자료를 개인 단위 또는 연령별로 결합하지 않습니다. 두 통계는 모집단과 주기가 다릅니다.

재생성: `python scripts/prepare-data.py && npm run build`. 원본 SHA-256은 생성된 `statistics.provenance.files`에 저장합니다. 통계 패널은 실제 파일 기반이고 관광지 태그·개념도·예산 계산 가정은 예시입니다.

## 추가 원본

- `regional-visits.csv`: 제주 지역별 방문객(읍면동), 3,956행, 43개 읍면동 × 92개월(2019.01~2026.08). 각 행의 내국인+외국인=총 방문객수 일치 검증. 연령·성별·좌표 없음. 지역간 방문자 중복 여부가 불명확하므로 합산해 제주 전체 실인원으로 사용하지 않음.
- `domestic-satisfaction.csv`: 제주여행 내국인관광객 세부 만족도, 144행, 2014~2025 × 12개 항목. 공란 18개는 null로 보존. 점수 척도 상한·표본·연령 정보 없음. 지역·관광지별 평가로 해석하지 않음.
- 제주 지역별 인기 장소: 첨부파일이 32MiB 전송 한도를 넘어 수신되지 않았으며 아직 분석·반영하지 않음.
